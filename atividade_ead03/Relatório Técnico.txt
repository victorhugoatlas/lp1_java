# 1 - A Importância da Decomposição Funcional na Engenharia de Software
- Essa decomposição consiste basicamente em dividir um problema maior e mais complexo em problemas menores, especializados e independentes. O grande objetivo é melhorar a legibilidade do código, tornando o programa principal mais fácil de ler e compreender, onde ele atua como um orquestrador. Além disso, essa abordagem viabiliza boas práticas como o reuso, onde um mesmo pedaço de código pode ser utilizado em diferentes partes do projeto e testado unitariamente, facilitando a manutenção de todo o sistema, já que as funções possuem objetivos bem definidas simples.

# 2 - Diferença Prática entre Métodos Procedimentais e Métodos Funcionais
* Os Métodos Procedimentais (void) não retornam valores para quem os chama, tendo como principal objetivo executar uma instrução com efeito colateral (como exibir mensagens na tela) ou alterar uma estrutura de dados recebida (como um vetor). Já os Métodos Funcionais (return) retornam obrigatoriamente um valor de um tipo específico, sendo utilizados para processar informações, efetuar cálculos e realizar buscas, devolvendo o resultado obtido para quem os chamou.
